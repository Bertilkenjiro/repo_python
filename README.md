## 🚀 Projetos

### 🧾 [Formulário Flask](./formulario_flask)
Aplicação web simples criada com **Flask**, que permite:
- Coletar respostas via formulário HTML;
- Armazenar os dados em um arquivo CSV local;
- Exibir uma mensagem de confirmação ao usuário.

📦 Tecnologias utilizadas:
- Python (Flask)
- HTML / Jinja2
- CSV / manipulação de dados
